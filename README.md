# 🍫 Consumer Goods - Data Modeling Study Case

## 🎯 Project Objective
The objective of this project is to apply the concepts learned from Data modeling courses, including Conceptual, Logical and Physical data model implementation. 

A consumer goods fictitious company is being used as a study case to implement a data modeling project based on Sales, Product & Manufacturing and Supply Chain data.


## 🔧 Technologies Used
- Data Warehouse:	BigQuery
- Modeling diagrams:	Draw.io
- Documentation	README, PR

## 🏛️ Project Content

The project includes:

- Conceptual Model

- Logical Relational Model

- Physical Schema (BigQuery)

Example fact tables:

- t_fct_sales_order
- t_fct_inventory
- t_fct_payment

Example dimension tables:

- t_dim_product
- t_dim_sales_channel
- t_dim_factory

## 📦 Datasets Included

The project simulates typical consumer goods datasets:

📊 Sales Data

- Payment
- Customers
- Sales channels
- Sales Order
- Sales Order Items

🥫 Product & Manufacturing

- Products
- Categories
- Production batches
- Factories

🚚 Supply Chain

- Inventory
- Warehouses
- Deliveries
